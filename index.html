Why another format?

Because config files should be easy for humans to write.

JSON has no comments, demands quotes on every single key, and crashes if you accidentally leave a trailing comma. It was built for computers to talk to each other, not for humans to write by hand.

JASD (Just Another Static Database) solves this. It keeps the familiar bracket structure of JSON, but removes the annoying rules. Plus, it comes with powerful tools to read, write, and search your files.

Simple Syntax

Keys don't need quotes. Trailing commas won't break it.

Native Comments

Use -- to write notes anywhere in the file.

Python Library

Instantly pip install jasd to filter data and do math.

Cross-Platform

Use it in Windows with the CLI, or in web browsers.

Quick Start

Everything you need to know to get started.

1. The Python Library

If you are building a backend, a Discord bot, or a data script, JASD is a native Python package. You can install it instantly using pip.

bash
$ pip install jasd

Once installed, you can import it just like the standard json module. It contains a full data processing engine.

Python
from jasd import load_file, query, sum_data # 1. Load your data file data = load_file("games.jasd") # 2. Query it like SQL (find cheap RPGs) cheap_rpgs = query(data, "price < 30 and category = RPG") # 3. Do math instantly total_money = sum_data(data, "price") print(f"Total: ${total_money}")

2. The Web Engine

If you want to load `.jasd` files into a website, you don't need Python. You just need the jasd.js parser file. Place it in the same folder as your HTML.

index.html
<!-- 1. Load the parser --> <script src="jasd.js"></script> <script> // 2. Fetch your data file fetch('data.jasd') .then(res => res.text()) .then(text => { // 3. Parse it into a JS array const data = parseJasd('data.jasd', text); // 4. Use it like normal JavaScript! console.log(data[0].name); }); </script>

3. The Windows CLI

If you want to view, format, and compile files visually, run the jasd-setup.exe installer. It adds the `jasd` command to your system.

Command Prompt
C:\Users\You> jasd compile data.jasd ✓ Compiled to data.json C:\Users\You> jasd

Syntax Guide

It's just JSON, but without the headaches.

JASD supports arrays, nested objects, booleans, and native comments.

data.jasd
JASD-V1 [ { id: 1 name: "Hades" price: 25 inStock: true tags: [roguelike, action] -- This is a native comment }, { id: 2 name: "Minecraft" price: 30 inStock: false tags: [sandbox, survival] } ]

Data Types

JASD automatically infers types without you needing to specify them.

  • Numbers: Parsed as floats/integers (e.g., 25, 3.14).
  • Booleans: true, false, yes, no are evaluated as native booleans.
  • Arrays: Enclosed in [] and comma-separated.
  • Strings: Any bare word. Quotes are optional unless the string contains a colon.

Python Library

Data science, automation, and backend queries.

The Python version is not just a parser; it's a full data processing toolkit. You can import it just like the standard json library.

Python
from jasd import load_file, query, sum_data data = load_file("games.jasd") # SQL-Style Querying cheap_rpgs = query(data, "price < 30 and category = RPG") # Built-in Math Engine total = sum_data(data, "price")

Advanced Features

  • from_csv() and to_csv() for Excel/Pandas integration.
  • find_duplicates() to clean up your databases.
  • dump_secure() to encrypt your data files with a password.

Q&A

Frequently asked questions.

Is JASD faster than JSON?

For small config files, they are roughly the same speed. However, because JASD ignores strict formatting rules like missing commas or unquoted keys, the parser uses a slightly more forgiving regex/tokenizer, which means for massive files (10,000+ rows), JSON might technically parse in 10ms while JASD parses in 12ms. The tradeoff is worth it for human readability.

Can I use this in a real production environment?

Yes! The Python library is fully published on PyPI, and the Go CLI compiles down to a standalone binary. As long as you test your implementation, it is just as stable as JSON.

Why does the file need to start with JASD-V1?

This is called a "Magic Header". If you accidentally try to parse a `.json` or `.txt` file, the parser will instantly throw an error saying "Missing JASD-V1 header" instead of trying to guess and crashing. It also allows us to release JASD-V2 in the future without breaking older files.

Can it handle nested objects and arrays?

Absolutely. Even though you don't need quotes, JASD uses the same `{}` and `[]` bracket structure as JSON, meaning it can nest data as deeply as you need.
